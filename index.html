클라이언트 ID 발급 방법 보기
  1. Google Cloud Console에서 새 프로젝트를 만들고 Google Drive API를 사용 설정합니다.
  2. OAuth 동의 화면에서 외부(테스트) 앱으로 설정하고 본인의 구글 계정을 테스트 사용자에 추가합니다.
  3. 사용자 인증 정보 → OAuth 클라이언트 ID 만들기 → 웹 애플리케이션을 선택합니다.
  4. 승인된 자바스크립트 원본에 현재 주소 를 추가합니다.
  5. 발급된 클라이언트 ID를 위 입력칸에 붙여넣고 저장한 뒤 로그인하세요.
